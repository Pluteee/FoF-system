# 绩效监测评价（本地内部试评）

入口：国家版主菜单“绩效监测评价”；区域版“管”下同名入口。子基金版可查看、建立本基金评价。角色隔离只是单浏览器演示，不是生产权限控制。

## 政策口径

- 发改财金规〔2025〕1753号《政府投资基金投向评价管理办法（试行）》及附件：政策符合性60分、生产力布局30分、政策执行能力10分。13项二级指标在本演示拆成26个核查评分点；IRR仅为其中1分。原附件及主管部门的解释优先，平台不代行官方认定或发布等级。
- 财预〔2020〕7号：政策目标实现程度、财务效益、管理水平及全过程绩效管理。单独提供目标—实际—偏差—整改—核查闭环视图，不编造财政部统一评分权重。
- 不以一个项目或一个年度的盈亏直接否定整个基金；保留生命周期阶段、早期投资特例和未实现收益说明。

官方来源：

1. [发改委办法与附件](https://www.ndrc.gov.cn/xxgk/zcfb/ghxwj/202601/t20260112_1403195.html)
2. [财政部全过程绩效管理要求](https://www.mof.gov.cn/zcsjtsgb/gfxwj/202002/t20200212_3583753.htm)
3. [财政部高质量发展答记者问](https://m.mof.gov.cn/czxw/202501/t20250107_3951292.htm)

## 使用流程

1. 单选/多选区域母基金或子基金，确定年度、截至日、生命周期及批次。系统冻结当期已确认报送的最近版本；不把季度累计数相加。
2. 添加补充文件或人工摘录，核对对象、期间、原件位置、事实与本期核验截至日。文件解析成功不等于已核验。
3. 逐指标引用证据，填原始事实，计算建议分或说明人工审定依据。信用、披露等指标须有相应部门依据。全国就业基准不可用本批样本排名替代。
4. 核查负面清单：未决线索不能直接认定，未查询不能推定无异常；有认定事项时不自动发布完整试评分。
5. 区域母基金以直投部分和已复核子基金报告、对应资金进行穿透加权。资金总额须完整勾稽，不剔除缺项后重新归一化；不平均IRR代替绩效分。
6. 同类型、同年度、同截至日、同阶段、同规则比较；生成报告草稿或完整内部试评，留存人工复核意见。报告冻结，底稿变化另出新版。

在“财政绩效监测”下另有“战略成效补充监测”：早期资金放大倍数、非政府社会资本实缴、硬科技/原始创新已投企业覆盖。三项不额外增加官方权重。区域任务的有效证据和核验实际数同步至驾驶舱区域比较；子基金不自动合并以免重复穿透。修改引用证据会将成效核验作废，待重新核查。倍数按同期间同企业群全部早期实际投资（含本级资金）÷本区域财政穿透投资计算，不是IRR或净新增撬动倍数。

## 数据与文件边界

- 申请/拟出资、目标规模、演示底层关系只作监测线索，不自动证明实缴、已投、政策成效或IRR。当前登记线索可能晚于评价年度，不能冒充该年度实投快照。
- 支持PDF可选文字、DOCX正文/表格段落、XLSX单元格及公式缓存、TXT、MD、CSV、JSON。扫描PDF/图片不做OCR；旧版DOC/XLS须转换。Word不提供真实页码，Excel不重算公式。
- 单文件20MB、PDF200页、提取文字30万字；压缩文档有展开体积与条目限制。这些是演示防护，不替代生产级恶意文件检测。
- 原件保存在浏览器IndexedDB，底稿保存在localStorage；均不上传。浏览器清理、容量限制会影响本机数据，应及时导出。非企业证据库、非加密存储、非跨设备同步。
- 评价助手为规则与证据缺口辅助，未接真实大模型、OCR、外部信用查询或主管部门评价系统。文件内容按数据处理，不执行其中指令；人工核验是必要环节。
